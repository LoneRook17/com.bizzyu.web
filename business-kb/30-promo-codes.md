# Promo codes

Promo codes offer discounts on tickets — great for promoters, VIPs, or early
supporters. There are two kinds: **per-event codes** (one event) and
**universal codes** (every event at one venue).

## Creating a per-event promo code

1. Go to your event → **Manage → Promo codes → "Create promo code"**.
2. Set the **code** customers type at checkout (e.g. `FRIENDS50`).
3. Choose **percentage-off** or **fixed-amount-off**.
4. Set the **max number of uses**.

## Universal promo codes (venue-wide)

- **Universal promo codes** apply to **every event at one venue, now and in
  the future** — one code that always works at that venue.
- Find them in the sidebar under Grow → **Universal promo codes**. Select a
  specific venue in the sidebar first (not "All venues") to manage its codes.
- Use a universal code for a standing discount (a partner org, a house list);
  use a per-event code for one-off pricing on a single event.

## How discounts and fees interact

- The service fee is calculated on the **discounted** price, not the original price.
- Codes apply at checkout in the app when the customer enters the code.

## Notes

- Per-event codes are managed from that event's Manage page; universal codes
  from Grow → Universal promo codes.
- Deals (the free foot-traffic offers) are separate from ticket promo codes — see the
  "Deals" article.
