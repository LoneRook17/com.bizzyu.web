1. How to create an event

Use this for one nights - theme parties, guest DJs, ticketed shows.

  1. Open the Bizzy app and go to the Host tab.
  2. Create a new event.
  3. Fill in the basics: - Event name - Venue / location - Date and doors / start time - Flyer or cover image
  4. Add ticket types (e.g. General, VIP, 18+, 21+). - Set price and quantity for each.
  5. Optional: promo codes, promoter commission, capacity.
  6. Publish when ready.

Students buy in the app or via the event link. At the door you scan tickets with the Bizzy scanner and take walk-ups with Tap to Pay.

Tip: Add door people as co-hosts / crew (or share a door code) before doors open - not after the line forms.

2. How to create weekly cover / skip-the-line passes

Use this for recurring nights - every Friday cover, Saturday skip-the-line, etc.

  1. In Host, create a Weekly Cover / door-access series (or recurring night).
  2. Pick the day(s) of the week and the window (e.g. Fri 9pm - 2am).
  3. Add pass types, for example: - Cover - entry for the night - Skip the Line - prepaid skip / cover combo
  4. Set prices (and age tiers if you use them: 18+ / 21+).
  5. Turn the series on so it posts every week automatically.

Students buy ahead or at the door. Each night in the series gets its own sales.

3. How weekly cover works at the door

Weekly Cover / skip-the-line uses a pink QR. This is different from normal tickets.

Important (current product)

ActionWhat to use
Check a prepaid pink passPhone Camera only (any iPhone or Android)
Sell cover / skip to a walk-upTap to Pay in Bizzy (Host tab or door code)
Bizzy in-app scannerDoes not redeem Weekly Cover pink QRs - do not use it for pink

Pink QR = phone camera

  1. Guest opens their pink pass in Bizzy.
  2. Door staff open the phone Camera app (not the Bizzy scanner).
  3. Point at the pink QR → entry validates.
  4. No Bizzy account required for the person checking the pink QR.
  5. No scanner setup required for pink.

Walk-ups the same night

If they didn’t buy ahead → sell cover / skip with Tap to Pay in Bizzy (see Tap to Pay).

You’ll switch between Camera (prepaid pink) and Bizzy / Host (Tap to Pay).

4. Bizzy scanner (ticketed nights)

The Bizzy scanner is for ticketed events (normal ticket QRs), not Weekly Cover pink passes.

BenefitWhy it matters
Faster ticket scanningBuilt for door volume on ticketed nights
In-depth analyticsLive check-ins, who scanned what, pre-sale vs door, staff breakdown
Same place as Tap to PayHost / door code: scan tickets and sell walk-ups without leaving Bizzy

Bottom line

  • Weekly Cover / skip (pink) → Camera to scan + Bizzy Tap to Pay for walk-ups
  • Ticketed event → Bizzy scanner + Tap to Pay in Host / door code

5. How to add staff to your team

Two different places (don’t mix them up):

A. Business team (ongoing staff)

Add managers and staff who help run the bar on Bizzy year-round.

  1. Open your business / team settings in Host (or business dashboard).
  2. Invite by phone or email.
  3. Pick a role: Manager or Staff (see next section).
  4. They accept the invite in the app.

Business team access helps with weekly cover programs and day-to-day Host tools.

B. Event team (that night’s door)

For a specific event, add people who only work that night:

  1. Open the event → Team.
  2. Add them as Co-host or Crew.
  3. Or skip invites and share a door code (fastest for door-only people).

Rule of thumb: if they’re only scanning tickets / taking door money tonight → Co-host / Crew or door code. Don’t make them a business Manager just to work the door.

6. Staff role vs Co-host role

Business roles

RoleWhat they can doWhat they usually don’t
OwnerEverything - payouts, Stripe, ownership, events, team -
ManagerRun events / weekly cover, team, door toolsOwn the Stripe account / transfer ownership
StaffHelp operate Host tools; more limited editsChange money settings, delete the business
PromoterSell via personal link / commissionRun the door or edit events

Event roles

RoleWhat they can doBest for
Owner (event)Full control of that eventWho created / owns the night
Co-hostManage the night, scan tickets, Tap to Pay, team helpsTrusted managers for that event
CrewScan tickets + door salesDoor staff for one ticketed night

Simple version

  • Staff (business) = part of your bar’s Bizzy team ongoing.
  • Co-host (event) = trusted on *that* night (tickets, pay, help run).
  • Crew / door code = door-only: scan tickets and take payment without full ownership powers.
  • Weekly Cover pink check-in = anyone with a phone Camera (Bizzy login optional).

7. Door staff guide

Weekly Cover & Skip the Line (pink)

  1. Guest opens their pink pass QR in Bizzy.
  2. Staff open phone Camera → point at the pink QR → confirm entry. - Do not use the Bizzy in-app scanner for pink - it won’t redeem Weekly Cover.
  3. If they didn’t buy yet → open Bizzy Host (or door code) → Tap to Pay → sell cover / skip.

Ticketed events (non-pink tickets)

  1. Guest opens their ticket QR in Bizzy.
  2. Scan with the Bizzy scanner (Host tab or door code).
  3. Green / success = they’re in. Don’t double-scan.
  4. Walk-ups → Tap to Pay in the same Host / door-code flow.

Pink QR reminder

PINK QR codes (Weekly Cover / skip) = scan with any phone camera.
You do not need to be set up on the Bizzy app to check pink.
Use Bizzy Host / door code for Tap to Pay walk-ups.
The Bizzy scanner does not work for Weekly Cover pink passes today.

8. Tap to Pay

Every staff iPhone can be a card reader. Bar keeps the door money (Bizzy’s door fee model stays 0% platform cut as agreed for your venue).

When to use it

  • Walk-ups who didn’t buy cover / tickets ahead
  • Selling cover or skip at the door on Weekly Cover nights
  • Card instead of cash on ticketed nights

How staff start Tap to Pay

Path 1 - Host tab (logged-in staff / co-host)

  1. Open Bizzy → Host tab.
  2. Select tonight’s event / weekly cover night.
  3. Open Tap to Pay (or door sales).
  4. Enter amount / pass type → hold iPhone near the guest’s card or wallet.

Path 2 - Door code (no full account)

  1. Host opens the event / night and copies the door code.
  2. Text or tell door staff the code.
  3. Staff open Bizzy → enter the door code.
  4. They can take payments (and on ticketed nights, scan tickets).

On Weekly Cover nights: Camera for prepaid pink, Host/door code for Tap to Pay.
On ticketed nights: Host/door code for both scan + Tap to Pay.

9. Host tab + door code

Host tab

Logged-in owners, managers, co-hosts (and staff with access) use Host for:

  • Tonight’s event / weekly cover list
  • Ticket scanning (ticketed nights)
  • Tap to Pay
  • Live counts / night tools

Door code

  • Generated for the event / night
  • Share with door staff
  • They enter it in the app → Tap to Pay (and ticket scan on ticketed nights)
  • No need to add them as business Owner or Manager

Pick one per person

PersonBest setup
Manager who works every weekBusiness Manager + Host tab
Trusted night leadEvent Co-host
Door-only on a ticketed nightDoor code (or Crew) - scan + pay in Bizzy
Weekly Cover pink-QR checkerPhone Camera (required for pink)
Weekly Cover walk-up salesHost or door code → Tap to Pay

Night-of checklist

Before doors

  • [ ] Event or weekly cover night is published / live
  • [ ] Ticket / cover prices look right
  • [ ] Staff know which night it is:

- Weekly Cover → Camera for pink + Tap to Pay for walk-ups

- Ticketed → Bizzy scanner + Tap to Pay

  • [ ] Co-hosts / crew added or door code shared (for Tap to Pay / tickets)
  • [ ] At least one iPhone ready for Tap to Pay

During

  • [ ] Pink Weekly Cover / skip → Camera only (not Bizzy scanner)
  • [ ] Ticketed tickets → Bizzy scanner
  • [ ] Walk-ups → Tap to Pay
  • [ ] Don’t re-scan a pass that already checked in

After

  • [ ] Check Host / dashboard for sales
  • [ ] Confirm payout path is set (owner)
